# SSH 传输压缩单变量测试

2026-09-20。相同 JSON 请求字节、会话 salt、服务与固定 OK 回复，分别经 Compression=no/yes 的独立 SSH 隧道发送；禁止复用已有 SSH master。首两个调用为预热并保留，随后十对随机交错请求，串行 C1，测试期间没有其他测试器并发推理。请求约 16K token；这不是 Agent 任务验收。

22/22 回复正确。预热后的中位 HTTP 延迟无压缩 0.788 秒、有压缩 0.740 秒，减少约 6.1%；服务端中位耗时分别 0.374、0.375 秒。十对中八对压缩更快，有明显时序噪声，样本不足以宣称生产稳定收益。请求体本身有大量重复前缀，不能推断普通流量都有相同比例。后续完整 Agent 的复用路由试验没有启用此选项，以免混淆。
