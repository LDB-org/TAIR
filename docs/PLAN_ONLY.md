# 严格 plan 模式（历史固定任务实验）

后续已改为[通用 Pi 工具 plan](GENERIC_PLAN.md)。本文的固定验收模式现在必须显式添加 `--verified-modules`；不再是 `--plan-only` 默认行为。以下保留当时实验口径。

`node integrations/pijit/launch.mjs --plan-only` 配合可信 `PIJIT_PLAN_VERIFY_ARGV` 启动。
原版 read/write/edit/bash 及 compact_edit 等工具均不可执行。Pi 启动白名单、扩展
执行拦截、bridge 模型工具过滤及返回值校验共同限制路径；每个用户新轮次首先请求
plan，包含已有对话历史时也生效。最终文字回复不属于工具调用。

此模式开启新 Python 模块生成、引擎分类、动态 SQLite 码表以及强制验证。
缺失验证器会在启动隧道前报错；验证失败最多一次内层强制生成恢复，不回退到原版工具。
只支持创建新文件，不支持任意仓库维护，不能用编译检查冒充可信语义验证。

2026-09-20 实测使用本地 Pi 0.85.1，通过 SSH 连接 yuesheng 既有 5090 服务；没有
安装补丁或重启服务。固定 UTF-8 文件读写任务，冷/热两轮使用同一临时工作区、不同
新文件名及同一空库起步，完整 Agent 每轮运行后再独立验证产物。

| 轮次 | 含启动及隧道总耗时 | 推理请求 | 生成 token | 分类控制 | 入表/复用 |
|---|---:|---:|---:|---:|---|
| 冷 | 10.084 s | 3 | 665 | 1 | 新增 1 条 |
| 热 | 9.267 s | 3 | 521 | 1 | 复用 1 条 |

两轮外层可用工具均严格为 `plan`，无普通工具调用；第二轮源码与第一轮完全相同，
库内成功复用计数为 1，独立行为检查通过。推理包括外层构造请求、内层分类/生成、
外层总结三次；不能把“只有一个 plan 工具”说成“完整任务只有一次模型请求”。
仅一对固定任务，不用于泛化加速结论。
