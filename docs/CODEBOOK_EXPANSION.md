# 码表扩展与扩大验证（2026-09-18）

本轮实现扩大了生成结果的入表范围，并分别验证编辑内部、候选拒绝和完整 Agent。
**编辑内部有明确收益，完整 Agent 本组仍没有净加速。**

## 实现变化

- 明确 CLI 请求可学习整数、浮点、字符串、布尔参数和别名模板，之后重新绑定值。
- 条件返回、抛异常、异常捕获、多处编辑也可入表；当前仅支持原任务和原源码精确复用。
- 明确绑定的模板允许普通注释/格式变化后的 AST 等价源码；实际代码变化仍失效。
- 别名导致的目标名称变化会随结果快照更新；写入前仍检查当前源码字节。
- 分类提示解释操作字段，明确绑定与精确任务均检查适用性；NONE 保留生成回退。
- 生成结果若违背已完整解析的明确请求，在写入前拒绝。候选去重，检索复用预计算哈希。
- Pi 工具说明明确紧凑编辑适用范围，支持同一文件最多八处相关修改合并调用。

没有修改模型权重、vLLM 服务或生产部署，没有开启预设/Schema 执行、精确零请求重放或
本地确定性路由。本轮新增的是现有分类优先路径的学习与复用能力。

## 编辑内部：11 类任务，372 次执行

三组各 124 次，包含首次、重复、变参、连续修改、注释变化和实际代码变化。
每次启动独立 Python 进程，检查码表跨进程持久化，三组交错执行并使用相同行为检查。

| 指标 | 朴素 vLLM 工具调用 | 上一版 TAIR | 本轮 TAIR |
|---|---:|---:|---:|
| 行为检查通过 | 124/124 | 124/124 | 124/124 |
| 复用次数 | 0 | 18 | 64 |
| 编辑总耗时 | 141.06 秒 | 52.58 秒 | 41.28 秒 |
| 包含新进程启动的总耗时 | 150.17 秒 | 62.34 秒 | 50.70 秒 |
| 生成 tokens | 14,328 | 1,416 | 838 |
| 分类控制记录 | 0 | 124 | 124 |

编辑总耗时比上一版下降 **21.5%**，比普通工具调用下降 **70.7%**。生成参数比上一版
减少 **40.8%**。所有生成、分类、输入和进程成本分别记录；不把控制记录当零计算。
剔除相同的八个 AST 无变化任务后，收益仍成立，详见报告。

这是手写回归任务和共享后端的小规模对照；普通组使用同一已打补丁服务的普通接口，
没有另起未打补丁的 vLLM。不能将结果外推到所有任务、任意码表规模或生产吞吐。

## 候选拒绝

16 个直接候选检查覆盖错值、错目标、错属性、额外修改、类型混淆、否定和不完整复合任务。
新版 **10/10 错误候选拒绝、6/6 正确候选接受**；上一版为 9/10 和 6/6。
这是绕过检索的候选检查，不执行编辑，也不是校准后的总体错误率或语义安全保证。

## 完整 Pi：18 个任务

Pi 0.85.1，三个场景、冷暖两轮、三条路径：五个属性修改、别名、修复统计函数并补充测试。
每个任务包含读文件、规划、工具执行、测试、恢复及最终回复；暖机只保留码表，不保留对话。

| 指标 | Native Pi/vLLM | TAIR 禁用码表 | TAIR 启用码表 |
|---|---:|---:|---:|
| 完整任务通过 | 6/6 | 6/6 | 6/6 |
| 总耗时 | 69.55 秒 | 72.57 秒 | 73.45 秒 |
| 内层编辑推理次数 | 0 | 2 | 2 |
| 码表命中 | 0 | 0 | 1 |

启用码表组比原生组慢 **5.6%**。多属性修改成功通过紧凑编辑完成并暖机命中；
别名仍选择普通 edit，统计函数和测试修改走普通工具。外层工具选择、目录误读后的恢复、
上下文准备等开销占比较高，局部加速尚未转化为整体加速。

## 验证与边界

279 项单元测试通过；历史实验文件与新增校验清单通过校验。完整 Agent 在独立安装的
Pi 中运行，临时 SSH 隧道已关闭，原全局 Pi 与模型服务均未改变。

目前仍不具备任意自然语言的语义检索、任意程序模板归纳或完整 Agent 稳定加速。
默认编译验证只能说明语法成立；泛化模板与精确复用都继承原始验证强度。
后续应优先减少外层不必要调用、提高适用任务进入码表路径的比例，并用更长真实任务流
验证命中率与总成本，而不是继续只扩大单次 token 缩减比例。
