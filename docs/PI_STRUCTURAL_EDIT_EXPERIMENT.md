# 有限结构操作＋表达式生成实验

2026-09-18。实现 `deploy/structural_edit_protocol.py`，测试模型选择有限编辑操作、生成表达式值，由运行时构造语句结构。
这是未训练的新协议实验，不是新增分类头，也不是完整自主 Agent 测试。

## 实现

- `arg(call, expression)`：插入位置参数，用于参数别名等。
- `kw(call, name, expression)`：插入或替换关键字参数。
- `guard_return(function, condition, value)`：在 docstring 后、首条执行语句前添加 if/return。
- `guard_raise(function, condition, exception)`：同样位置添加 if/raise。
- `catch_return(statement, exception_type, value)`：把完整原语句放进 try/except，异常时返回指定值。

引擎端 regex 限定操作与对应类型的现有目标 ID，模型生成 JSON 字符串形式的表达式值。
表达式必须能以 eval 模式解析，再由 ast.unparse 渲染；不是 eval 执行模型表达式。
运行时绑定源文件 SHA256，所有操作使用原始坐标，拒绝重叠、未知目标和截断，最后 compile 检查而不执行。
新增控制流的缩进完全由运行时构造，不需要模型输出层级。

当前采用标准库 AST 的精确源码区间编辑，**没有安装或实现完整 CST 编辑器**。
原有代码、注释与未编辑文本保持原样；仅新表达式规范化渲染。支持统一空格或 tab 缩进，混合缩进拒绝。
移动含跨物理行字符串的语句会拒绝，避免改变字符串值；同一位置重复插入及不独占物理行的语句包装也拒绝。
新功能明确 opt-in，未更改旧协议或现有 GPU 服务默认配置。

## 预先冻结的方法

- 原生实际 Pi edit 对照；结构操作失败或隔离测试失败后，最多一次真实原生回退，从 pristine 文件重新开始。
- 6 类任务，每类两次，共 12 对，顺序打乱，原生/结构先后交替。
- 4 类旧任务：全部短参数别名、空端口早返回、socket 创建异常、紧凑 JSON。
- 2 类新增需求：workers 默认 6、socket 创建前拒绝 timeout > 60。这两类属于既有操作覆盖范围，不能当作跨项目泛化证明。
- 未向模型指定正确操作或目标；所有任务使用同一个操作目录与协议提示。模型只见任务和源码，不见测试。
- temperature=0，thinking 关闭，max_tokens=4096，每次请求新 cache salt。共享 yuesheng 模型服务，排队负载未隔离。
- 新增测试须先在原文件上失败；每个成功编辑还须通过原有 17 项 unittest。执行在 bubblewrap 私有网络内，仅 loopback。
- 完整成本包含失败、原生回退、修改应用及测试。协议和提示开跑后不再调整。

测试选取的是操作支持范围内的任务，没有测未覆盖的自由编程，也没有实现请求内主动选择原生路径。
运行时仍不提供跨进程文件提交的原子 CAS，不代表生产可靠性已完成。

## 第一轮完整结果（a）

| 指标 | 原生 | 结构操作＋回退 |
|---|---:|---:|
| 首轮成功 | 12/12 | 6/12 |
| 最终成功 | 12/12 | 12/12 |
| 输出 tokens | 2546 | 2008 |
| 输入＋输出 | 31074 | 49986 |
| 完整任务累计耗时 | 150.32 s | 131.76 s |
| 引擎累计排队 | 83.78 s | 54.72 s |
| 引擎累计生成 | 31.58 s | 32.92 s |

输出减少 21.13%，总 tokens 增加 60.86%。墙钟减少 12.35%，但排队较少，且按任务聚类 bootstrap 区间跨零，未通过预设加速筛查。

没有缩进失败。六次回退来自三类语义错误各两次：

- 别名：选择 kw 写入 option_strings，而不是 arg 插入位置参数。
- 异常处理：选择 guard_raise(True, False)，没有捕获 socket 创建异常。
- 紧凑 JSON：把 separators 加到 print，而不是内部 json.dumps，参数值也有误。

空输入早返回、默认值和 timeout 上限检查均首轮通过。

## 第二轮方法（b）

观察 a 后增加可读目标标签（函数名、调用名、语句片段）及通用 arg/catch_return 示例，
并把结构组用户提示中的“one edit operation”澄清为“一次数组包含全部操作”。
运行时与 grammar 不变。相同六类任务各一次，重新请求原生对照；无第三轮调参。
这是开发集调试，不能当作独立泛化提升。
启用参数为 `--semantic-targets --repeats 1`，证据目录 `pi-structural-edit-20260918-b`。
标签和示例增加的输入完整计入成本。

## 结论与代码验证

有限结构操作能消除这些任务中由模型生成缩进的需要，并显著缩短成功调用的输出。
目前总成本受操作说明、目标目录和失败回退支配，不能宣称已经实现净 token 节省或生产加速。
尚未测试协议训练、目录缓存/压缩、未覆盖操作的直接路由及真实多轮 Agent 链路。

103 项 pytest、原始 raw 哈希及 69 项 published claims 校验通过。
实测完成后，本地另外修正了“位置参数插入”在关键字先于 starred 参数时的源顺序处理，新增单测验证；
该补充未重跑 GPU，两个实验目录 sources 保存的是各自实际执行版本。

后续压缩目录、类型化参数与任务范围筛选的完整实验见 [结构协议优化](PI_COMPACT_STRUCTURAL_OPTIMIZATION.md)。
