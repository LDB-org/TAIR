# Rich 码表路由优化与复测

## 改动

参数绑定器现在支持模块顶层 `if __name__ == "__main__"` 中的直接 `add_argument` 语句。解析器构造必须是同一块中更早的直接赋值；`import argparse` 必须位于模块顶层或该块内，并早于构造。main guard 不建立词法作用域，因此检查整个模块中的解析器赋值是否唯一。

这是通用源码布局支持，没有写入 Rich 专用候选或改写任务。原有唯一目标、字面量类型、遮蔽和别名 destination 检查保留。任意条件块、嵌套 guard、条件/过晚导入、重复赋值仍被拒绝；函数内局部 import 尚未支持。只有进入 compact_edit 的操作才能学习复用。

新增回归测试覆盖路由、首次学习、修改后的源码继续换值复用（不恢复源码）、命中零模型调用、实际 argparse 行为、别名可路由及拒绝时不写文件。完整测试 347 项通过。

## 方法

沿用上轮 Rich v13.7.1，commit `7f580bdcf07a3b269a0e786b6a3aa9c804f393cf`。同样的提示、独立 oracle、120 秒时限；3 组 × 2 次独立重复 × 8 步，共 48 次完整 Agent 尝试。每次独立重复从空表开始。原生使用普通 tools API 并允许并行工具；两个 TAIR 组只差关闭码表开关。

默认值和短别名各含首次、同值重复、新值三轮；UTF-8 和负数校验各一轮。热轮恢复上游原始源码，与此前一致，不代表任意连续源码演化都能命中。没有把 oracle 提供给 Agent 或用作运行时项目验证。通用无绑定编辑不自动学习。夹具及 oracle 未改，保留此前预检记录作为继承证据，并非本轮重新预检。

Pi 与工具在本机 macOS 隔离环境执行，经 SSH 请求 yuesheng 既有 5090 服务。没有重启、打补丁或改变搜索策略。完整计时含启动、规划、工具、检查、最终回复和外部验收；编辑 bridge 内部时间不含 Python 子进程启动。历史前后测不是随机对照速度证据。

### 热复用：8 次全部正确

| 指标 | 关闭码表 | 开启码表 |
|---|---:|---:|
| 编辑 bridge 合计（秒） | 9.930410 | 0.098647 |
| 编辑模型请求 | 8 | 0 |
| 外层模型请求 | 34 | 38 |
| 完整任务合计（秒） | 91.398862 | 90.034134 |

编辑阶段节约 **9.831763 秒，99.01%**。完整任务仅节约 **1.364728 秒，1.49%**；其余时间增加约 8.467 秒，且开启组多了 4 次外层推理。不能把编辑阶段比例宣传成 Agent 总体加速。原生同样 8 个热任务全部通过，合计 97.700030 秒；这包含规划与工具接口差异，不能全归因于码表。

上轮 Rich 所有 compact_edit 调用为零；修复后开启组 12 个适用步骤中，4 次首次生成，8 次热复用。两次从空表开始均复现。这个预先设计的重复比例不等于生产命中率。8 次命中均为确定性模板绑定，不是模型分类选中了缓存。

### 失败与边界

- 第一次 UTF-8 任务的两个 TAIR 组执行 `find / -name "json.py" -path "*rich*" 2>/dev/null` 后触发 120 秒时限，未完成任务，代码也未通过验收。没有 compact_edit 或码表命中。搜索没有正常结束的工具结果，不能虚构精确搜索耗时；只读日志分析器明确不统计这种中断搜索。
- 第一次负数校验的开启码表组代码验收通过，但运行 pytest 产生 `.pytest_cache` 四个文件，被固定的无关文件检查记为失败。没有码表操作。保留严格原始评分，不在看到结果后排除缓存文件。
- 第二次独立重复三组均 8/8 通过；完整时间原生 130.056 秒、关闭 112.997 秒、开启 112.934 秒，开启/关闭几乎相同。

本轮证实的是常见源码布局的路由覆盖和正确热复用；没有证明完整 Agent 普遍更快或更可靠。面向演示仍需处理外层全盘搜索和检查产物清理。仅四类有限任务，没有运行 Rich 全量上游测试。

## 证据

原始第三方源码与轨迹保留在本地 `results/experiments/three-goals-repository-rich-20260919-b/`，不提交上游评估数据。公开汇总为 `SAFE_CODEBOOK_RICH_ROUTING_RESULTS.json`。48 个产物重新验收，结论与原始记录一致；16 个结构化推理请求均核对到引擎旁路事件。服务启动时间、镜像、tokenizer 与健康状态前后一致，临时隧道已关闭。所有失败保留，运行器退出 1 是失败计数的预期结果。

复现命令沿用 `SAFE_CODEBOOK_RICH.md`，输出目录必须换新；本轮精确命令及源码快照保存在原始记录。测试结果和整个存档的 SHA-256 校验通过。
