# 保守动态码表：真实仓库完整 Agent 对照

本轮将码表实验从受控编辑阶段扩展到完整 Pi Agent，包含规划、读取、编辑、Agent 自行运行检查、最终回复和独立验收。运行时实现保持不变。

## 设计

- 服务：yuesheng 现有六张 RTX 5090，使用已部署服务，不安装补丁或重启。
- 上游：CPython v3.11.9，commit `de54cf5be371a6f5e2e9f208c38def5f81d3ef02`，固定 Tools/scripts 与许可证。
- 客户端：本机 macOS 执行 Pi 0.85.1 和工具，隔离 Python 3.11，通过 SSH 隧道请求远程 GPU 推理。每题新进程、新会话，2048 token 回复上限、120 秒任务上限。网络和本机工具耗时都在主计时内。
- 三组：普通原生多工具 API；原生规划的 TAIR 关闭码表；相同 TAIR 开启保守码表。两个 TAIR 配置只差 `PIJIT_DISABLE_CODEBOOK`，均设 `PIJIT_SAFE_CODEBOOK=1`。原生组与 TAIR 工具目录不同，因此它们是系统对照；码表开关两组才是直接消融。
- 原生基线使用同一已打补丁服务的普通 tools API，允许一次输出多个工具调用，并启用组内前缀复用。这不是独立部署的未修改 vLLM 服务。
- 每次独立重复从空码表开始，同一任务的三组使用同一绝对项目路径，各自保留独立状态。重复轮恢复上游源码；第 3 轮 CLI 任务更换参数。组别逐步随机交错，不做失败替换。

四类任务，两次独立重复，共 48 次完整尝试：

| 任务 | 每次重复轮数 | 内容 |
|---|---:|---|
| diff 默认值 | 3 | 首次 5、重复 5、新参数 7 |
| diff 短别名 | 3 | 首次 -C、重复 -C、新别名 -N |
| untabify 默认宽度 | 1 | 从 8 改为 4，保留显式覆盖、编码、备份与未修改文件行为 |
| md5sum 参数检查 | 1 | main 拒绝非正缓冲区，退出码 2、stderr 诊断、不得输出校验和 |

后两题是本实验系列新增任务，不曾用于此前码表运行时调优；它们不是对模型训练数据的盲测。四类任务仍仅来自一个仓库。

## 验收和计时

先检查每个原始输入不能通过目标验收、参考修改能够通过。参考修改与独立 oracle 均不注入 Agent 提示或运行时验证命令。Agent 按任务要求自行检查；最终独立执行 CLI 行为验收，并保护所有无关文件。MD5 任务额外审核 main 之外的整个模块 AST。

没有向运行时配置 `PIJIT_VERIFY_CMD`。因此，新模式中只有完整类型绑定可以学习复用；开放请求不能仅凭 Agent 最后声称测试成功就入表。该配置避免把最终任务答案当成中间编辑的验证条件，也意味着本轮不能证明通用编辑的验证后精确入表。

主计时从启动 Pi 到退出，加上同一独立 oracle；包含所有规划、工具执行、Agent 检查和回复。夹具恢复、产物复制及后验审计不计入。编辑内部计时取 bridge 自身 wall_seconds，不含启动 bridge 进程的开销，不能与主计时混称。

生成 token、分类控制记录、逻辑输入和推理请求分别统计。超时或用量不完整会单列，不把已知下界当成完整用量。

## 结果

48/48 个完整任务通过，保存产物再次独立验收也为 48/48，无超时，无缺失用量。没有发现暖复用导致错误修改。

| 指标 | 原生多工具 | TAIR 关闭码表 | TAIR 开启码表 |
|---|---:|---:|---:|
| 正确完成 | 16/16 | 16/16 | 16/16 |
| 完整总秒数 | 235.732 | 217.432 | 202.411 |
| 外层推理请求 | 105 | 77 | 75 |
| compact_edit 推理请求 | 0 | 12 | 4 |
| 全部推理请求 | 105 | 89 | 79 |
| 生成 token | 21,846 | 17,358 | 16,787 |
| 分类控制记录 | 0 | 12 | 4 |
| 逻辑输入 token | 308,101 | 230,062 | 214,950 |
| 码表命中 | 0 | 0 | 8 |
| 工具报错记录（均恢复） | 2 | 6 | 2 |

原生组的编辑参数由外层普通 tools API 生成，compact_edit 请求为零不等于没有编辑推理成本。

开启码表的 TAIR 相比原生组总时间少 **14.13%**；关闭码表相比原生少 **7.76%**。这是工具目录、明确请求路由、紧凑编辑和码表等组合的系统差异，不能全归因于码表。

码表开关的直接对照总时间少 **6.91%（15.02 秒）**。两次独立重复分别少 **2.55% 和 11.11%**，波动明显，不能将 6.91% 宣称为稳定生产收益。

### 暖复用与归因

| 八个暖任务 | 关闭码表 | 开启码表 |
|---|---:|---:|
| 完整秒数 | 110.722 | 93.922 |
| 编辑 bridge 内部秒数 | 9.773 | 0.079 |
| 编辑推理请求 | 8 | 0 |
| 外层推理请求 | 37 | 34 |
| 工具报错记录 | 4 | 0 |

8 次命中均为完整类型绑定，包含重复参数和新参数，均跳过编辑模型请求。冷轮实际生成后才有条目，无预装答案。暖编辑内部直接观察节省 **9.694 秒**，约为关闭码表组完整总时间的 **4.46%**。该口径不含 bridge 进程启动，不与上一轮包含启动和项目检查的毫秒数直接比较。

完整暖任务少 16.800 秒，但外层请求数和检查轨迹也改变了，不能把这 16.800 秒全部视为固定的码表收益。关闭码表组的暖任务出现 macOS 不兼容的 `sed` 命令，以及普通 `diff` 的非零退出码；相关恢复都计入总时间。随机交错与相同提示没有消除生成轨迹波动。

冷轮及不适用任务合计：关闭码表 106.710 秒，开启 108.489 秒，没有显示提速。两个新增任务全部通过、全部采用普通生成式编辑，没有 compact_edit 调用或码表命中；它们支持当前普通编辑路径可用，不支持通用编辑已能学习复用的结论。

### 判断

本轮提供了完整 Agent 中净收益的正向观察，同时进一步确认其规模受命中率和外层开销限制。相比受控编辑实验的 46.77%，完整任务的增益小得多。此前真实仓库 B 曾出现编辑省时而完整任务略慢，本轮结果不覆盖或替换那批证据。

四类简单修改、一个仓库、两次独立重复，尚不足以确认通用性或稳定收益。下一步应优先减少外层规划与验证往返、改善检查命令的环境适配，并扩大独立仓库和复杂任务覆盖。

16 个实际结构化生成请求全部核对到服务端分类旁路事件。服务启动时间、镜像、tokenizer 摘要和健康状态前后一致，临时隧道已关闭。336 项本地测试通过。派生指标及逐产物验收见 `SAFE_CODEBOOK_AGENT_RESULTS.json`。

## 证据与复现

原始目录为 `results/experiments/three-goals-repository-safe-20260919-a/`。它包含上游评估源码，按仓库约定仅在本地保存并校验，不提交 Git。公开报告只包含派生结果和复现脚本。

```sh
python benchmarks/benchmark_three_goals.py --url "$URL" \
  --tokenizer-revision "$VERIFIED_REVISION" \
  --repository /path/to/cpython-v3.11.9 --repository-expanded --safe-codebook \
  --out results/experiments/three-goals-repository-NEW \
  --cases cpython_diff_default cpython_diff_short_alias \
          cpython_untabify_default cpython_md5_positive_buffer \
  --rounds 3 --repeats 2 \
  --warm-cases cpython_diff_default cpython_diff_short_alias \
  --arms native_multi hybrid_no_book hybrid
```

保留既有任务、提示、模型设置和生成回退路径。没有为新任务添加专用运行时规则，也没有修复验证来源更新机制；本轮目标是观察当前实现的完整任务表现。
