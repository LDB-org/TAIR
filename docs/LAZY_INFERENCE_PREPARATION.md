# 只构造实际使用的分类提示与分支指令

2026-09-20。infer 原来总是构造默认目录；即使存在 branch_instruction，也会先调用
默认 instruction 或序列化默认 schema，再立即覆盖。现改为按原优先级只构造使用的一项。
没有专用提示/分支指令时的默认行为保持不变。减少的是本地临时字符串，不是模型输入。

新增回归验证专用提示路径不会读取无用描述或调用被覆盖的 instruction，并核对最终
请求参数；完整 509 项测试通过，归档 62623 条和 2853 个导入文件通过。

本地合成 15 分支（固定 Pi 0.85.1 的七种工具、七个内容候选、general），交替运行旧/新
infer 30 轮；tokenization 和 HTTP 使用桩，串行准备，只测文字构造。前后实际 messages
和 tails 逐项相等。去掉每次 69333 字符的默认 schema 序列化，后 29 轮中位耗时从
0.761 ms 降至 0.391 ms，约省 0.37 ms。候选内容为合成文本，不能将局部比值写成
端到端加速，更没有减少实际模型 token 数。

结果说明这只是小清理，不是主要性能瓶颈。本轮没有 GPU 推理、服务重启或默认开关改变。
