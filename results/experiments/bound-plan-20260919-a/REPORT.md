# 上下文绑定计划：省掉长输出的对照

2026-09-19，Yuesheng 5090 现有服务完成 45 次测试，全部产物验收通过。未安装补丁、未重启服务、未使用学习码表。

## 实现与边界

从已观察的源内容及允许的目标路径构建三个候选计划：复制 alpha、复制 beta、复制两者。另加 NONE 候选，表示必须生成新内容。候选构建函数只接收源内容和路径元数据，不读取任务、预期答案或验收结果。候选顺序按任务场景打乱。

分类结果可直接确定路径、操作及完整内容，程序包装为一个 plan，由外部执行器落盘。引擎负责候选 logits 分类；绑定、回退调度及 plan 包装仍在实验客户端，尚未新增引擎内部的通用计划状态机或服务路由。

这是已知内容的复制/批量复制测试，**不是未知代码生成、任意程序修改或完整 Agent 测试**。候选可在当前上下文直接构建，不需要历史命中。既有 copy 工具、源引用和短 ID 协议也能避免重复输出内容；本轮的普通短 ID 对照正是为隔离这个因素。

## 方法

五类任务，各组各重复三次：4 行、24 行、64 行复制、两个文件一起复制、无法由候选满足的新内容任务。最后一种需写出 1 到 5，每行一个整数。分类和短 ID 路径选择 NONE 后都回退完整生成，计入全部成本。

三个组看到相同源内容、候选描述和任务：

- 完整生成：生成包含目标路径及全部文字的 JSON。
- 普通短 ID：普通解码器限制为候选 token，生成一个字母，由程序展开。
- 分类绑定：现有引擎候选 logits 分类输出控制 ID，由程序展开，不生成内容。

同一固定随机顺序交错运行；每次请求新 cache namespace；没有剔除 warmup、失败或异常慢样本。总时间包括候选构建、每次 tokenization、推理、回退、外部执行和独立内容验收；初始目录创建和一次性的标签 token ID 初始化不在内，后者单列在 manifest。无并发压测，未测前向计算次数。

## 结果

| 范围 | 完整生成 | 普通短 ID | 分类绑定 |
|---|---:|---:|---:|
| 全部 15 个任务，各组 | 47.404 秒 | 15.553 秒 | 15.277 秒 |
| 可绑定的 12 个任务 | 44.529 秒 | 10.034 秒 | 10.104 秒 |
| 不可绑定的 3 个任务 | 2.875 秒 | 5.519 秒 | 5.173 秒 |
| 全部任务生成 token | 4146 | 99 | 84 |
| 全部任务分类控制记录 | 0 | 0 | 15 |
| 全部推理 API 请求 | 15 | 18 | 18 |
| 各组验收通过 | 15/15 | 15/15 | 15/15 |

可绑定部分，完整生成 4062 token，普通短 ID 生成 12 token，分类生成 0 token、输出 12 条分类控制记录。两条绑定路径的新内容回退都生成了 84 token；普通短 ID 另生成 15 个选择 token。

分类绑定对完整生成：全部任务省 **67.77%**；可绑定任务省 **77.31%**。但可绑定任务分类比普通短 ID 多 0.070 秒（0.70%），不能声称分类算子贡献了主要速度优势。全部任务分类略快于短 ID 1.77%，仍是小样本观察，推理阶段总时间仅相差约 0.03 秒。

单次均值：

| 任务 | 完整生成 | 普通短 ID | 分类绑定 |
|---|---:|---:|---:|
| 4 行 | 1.363 秒 | 0.796 秒 | 0.807 秒 |
| 24 行 | 3.068 秒 | 0.838 秒 | 0.796 秒 |
| 64 行 | 7.145 秒 | 0.969 秒 | 1.009 秒 |
| 两文件 | 3.267 秒 | 0.742 秒 | 0.756 秒 |
| 新内容回退 | 0.958 秒 | 1.840 秒 | 1.724 秒 |

未命中时分类再生成比直接生成多 **79.91%** 时间。不能拿高绑定比例的总收益推断任意工作负载，更不能把未命中成本隐藏起来。已知源内容仍然进入输入上下文；避免生成不代表避免 prefill。普通短 ID 与分类组逻辑输入 token 相同，均为 8409；完整生成组为 8724，输出指令不同。

## 工程结论

应优先把已有数据表达为引用或确定性操作，避免让模型重抄大段文字。这个收益不依赖码表，也不要求专用分类旁路。对于无法绑定的新内容，尽可能直接进入生成，避免无效分类；但跳过分类的覆盖率和正确性尚需另测。

不能据此宣称完整引擎内 plan 已实现或一般代码任务提速 67.8%。若接入项目主路径，需要真实编辑任务上的源引用/参数绑定、失效检查和完整 Agent 对照。
