# 参数绑定编辑：最小替换片段对照

2026-09-19，Yuesheng 5090 现有服务完成 54 次 Python 编辑测试，全部通过独立验收。上一阶段已提交为 `f353a627f5c47da4af46df6d6dabacbe5cc0de50`；本轮是其后的独立实验。

## 与复制实验的区别

基线生成最小 old/new 替换片段，不要求重写文件或复制无关长文本。三组均看到相同源码与候选计划；分类和普通短 ID 只选择计划，外部程序执行其已经绑定的路径和参数。没有使用学习码表，没有新增服务补丁，没有在引擎内执行工具。

候选编译器仅读取源码 AST，支持顶层整数 workers/timeout 的翻倍操作，构建各单点修改、全部 workers、全部 timeout 和二者一起修改的候选，另加 NONE。它不读取任务或验收答案；任务可以要求其中一项，也可以要求目录外的新值或函数修复。普通生成可以输出任何合法最小替换。

有限词汇是实验限制：它不是任意数值修改器，不代表通用代码理解。计划绑定仍在客户端；服务内只运行既有分类机制。本轮使用可执行的合成 Python 文件，不是上游真实仓库或完整 Agent 评估。

## 方法

六类任务，每组重复三次，固定随机顺序交错：单文件单字段、四文件同字段、四文件两字段共八处、四文件中只改指定一个、目录外新值 7、新函数求和逻辑。

三个配置：生成最小 edits、普通生成一个候选 ID、引擎 logits 分类候选 ID。候选组选择 NONE 后回退生成全部计入时间。每次请求新 namespace；不复用历史 KV/码表，没有去掉首次调用或慢样本。

计时包含 AST 候选构建、tokenization、模型请求、回退、文件修改和独立验收；初始文件恢复及一次性标签 ID 准备单列。源码修改通过 AST 精确对照，保护无关字段和文件；函数修复通过空列表、混合正负数和输入不变性测试。所有错误与产物均保留。

## 结论与后续

批量参数绑定在这组实际文件修改中仍有收益，幅度比重复输出长文本的实验明显小。决定收益的是可省掉多少输出以及未命中比例，不能把前轮 67.8% 套用到编程任务。

当前新函数任务甚至没有任何可用编辑候选，目录中只有 NONE，仍调用模型是可以明确消除的开销。下一步应加入“无候选直接生成”，再测能否保住批量收益；有候选但任务不匹配的情形仍需要可靠判断，不能只按题目名绕过。此优化尚未在本轮实现或计量。

对一般开发工作的结论仍需真实仓库、更丰富任务和完整 Agent 对照。本轮未改变主路径默认配置。
